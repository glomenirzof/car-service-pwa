# Как запустить приложение — пошагово

Инструкция для человека, который не программирует. Все команды нужно вводить в
окно «Терминал» (как его открыть — в подготовке, шаг 3), а после каждой нажимать Enter.

Здесь два варианта:

- **Часть А — посмотреть на своём компьютере.** Примерно 15 минут. Не нужно ни аккаунтов,
  ни ключей: приложение работает только у вас, с демо-данными.
- **Часть Б — запустить в интернете.** Около часа в первый раз. Нужны аккаунты
  Supabase и Cloudflare; после этого приложение открывается с любого телефона.

---

## Подготовка (нужна для обеих частей)

### 1. Установите Node.js

1. Откройте [nodejs.org](https://nodejs.org) и нажмите кнопку с пометкой **LTS**.
2. Запустите скачанный файл и нажимайте «Далее» / «Продолжить» до конца установки.

### 2. Скачайте проект

1. Откройте [страницу проекта на GitHub](https://github.com/glomenirzof/car-service-pwa/tree/claude/pwa-autoservice-implementation-0tl3eb)
   (войдите в свой аккаунт GitHub, если попросит).
2. Зелёная кнопка **Code** → **Download ZIP**.
3. Распакуйте архив, например в папку «Документы». Получится папка с именем
   вроде `car-service-pwa-claude-pwa-autoservice-…`. Это и есть **папка проекта**.

### 3. Откройте терминал в папке проекта

- **Mac:** нажмите `Cmd + Пробел`, введите «Терминал», Enter. В открывшемся окне напечатайте
  `cd ` (обязательно с пробелом), перетащите мышкой папку проекта в окно терминала и нажмите Enter.
- **Windows:** откройте папку проекта в Проводнике, щёлкните по адресной строке вверху
  (где написан путь к папке), сотрите путь, напечатайте `cmd` и нажмите Enter. Откроется
  чёрное окно «Командная строка». Используйте именно её, а не PowerShell: в PowerShell
  команда `npm` часто заблокирована настройками безопасности Windows.

Проверьте, что Node.js установился:

```
node -v
```

Должно появиться `v22…` или больше. Если пишет, что команда не найдена, закройте
терминал, откройте его заново (шаг 3) и повторите.

### 4. Установите зависимости (один раз)

```
npm install
```

Займёт 2–5 минут. Жёлтые строки `WARN` — это нормально. Если в конце нет слова `ERR!`,
всё в порядке.

## Часть А. Посмотреть на своём компьютере

### Запуск

В терминале в папке проекта:

```
npm run demo
```

Первый запуск занимает 1–3 минуты: создаётся база данных, серверная часть докачивает свои
  модули (нужен интернет). Когда появится
надпись **«Готово»**, браузер сам откроет первую демо-студию, а в терминале будут ссылки:

```
  GRAPHITE Detailing   клиенты:  http://127.0.0.1:5173/s/graphite/
                       кабинет:  http://127.0.0.1:5173/__demo/owner/graphite
  RotorLab Автосервис  клиенты:  http://127.0.0.1:5173/s/rotorlab/
                       кабинет:  http://127.0.0.1:5173/__demo/owner/rotorlab
```

Ссылки можно копировать в браузер. Пока демо запущено, окно терминала не закрывайте.

### Что попробовать

1. **Запись как клиент.** Кнопка «Записаться» → услуга → день и время → имя и телефон
   (подойдут любые) → «Записаться». Запись появится во вкладке «Записи».
2. **Кабинет владельца.** Откройте ссылку «кабинет» из терминала: вход произойдёт сам,
   без пароля (так только в демо). В «Расписании» листайте дни стрелкой вправо: демо-записи
   начинаются с завтрашнего дня. Там же будет и ваша запись. Посмотрите «Статистику» и «Ещё».
3. **Вид как на телефоне.** В Chrome нажмите `F12`, затем `Ctrl + Shift + M`
   (на Mac `Cmd + Shift + M`) и выберите модель телефона вверху страницы.
4. **Вторая студия.** Откройте ссылку RotorLab: то же приложение, но другой бизнес, цвета
   и услуги. Так выглядит «новая студия из одного файла настроек».

Помощник (AI) в демо отвечает, что недоступен: для него нужен ключ AI-сервиса (см. часть Б,
шаг 11). Запись при этом работает.

### Остановка и повторный запуск

- Остановить: в окне терминала нажмите `Ctrl + C` (на Mac тоже `Control + C`). Windows
  может спросить «Завершить выполнение пакетного файла?» — нажмите `Y` и Enter.
- Запустить снова: откройте терминал в папке проекта (подготовка, шаг 3) и выполните
  `npm run demo`. Демо-данные при каждом запуске создаются заново.

### Если не запускается

| Что видно | Что сделать |
|---|---|
| `npm` или `node` «не найдена» / «не является командой» | Node.js не установлен, или терминал был открыт до установки. Закройте и откройте терминал. |
| `ENOENT` … `package.json` | Терминал открыт не в папке проекта — повторите подготовку, шаг 3. |
| `EADDRINUSE`, `address already in use` или `could not bind` | Демо уже запущено в другом окне терминала. Закройте то окно или нажмите в нём `Ctrl + C`. |
| Windows: ошибка про `VCRUNTIME140.dll` или `MSVCP140.dll` | Установите «Microsoft Visual C++ Redistributable» (x64) с сайта Microsoft и запустите снова. |
| Что-то другое | Скопируйте текст из терминала целиком и пришлите мне. |

## Часть Б. Запустить в интернете

> Команды этой части я проверил на копии проекта у себя, но без доступа к настоящим
> Supabase и Cloudflare: вход в аккаунты, загрузка функций и сайта ещё ни разу не
> выполнялись по-настоящему. Если на каком-то шаге появится ошибка, пришлите мне текст
> из терминала целиком, и я разберусь.

### Что понадобится

| Сервис | Зачем | Цена на старте |
|---|---|---|
| GitHub | там лежит проект (аккаунт у вас уже есть) | бесплатно |
| [Supabase](https://supabase.com) | база данных, вход владельца, серверная логика | бесплатный тариф |
| [Cloudflare](https://dash.cloudflare.com/sign-up) | сам сайт | бесплатно |
| AI-сервис (необязательно) | помощник в приложении | по тарифу сервиса |

Проверьте условия бесплатного тарифа Supabase на их сайте: неактивные бесплатные проекты
могут ставиться на паузу. Для постоянно работающего бизнеса обычно берут платный тариф.

Все команды ниже выполняются в терминале, открытом в папке проекта (подготовка, шаги 1–4
должны быть уже сделаны).

### Шаг 1. Создайте проект в Supabase

1. Откройте [supabase.com](https://supabase.com) → **Start your project** → войдите через GitHub.
2. Нажмите **New project**:
   - **Name** — любое, например «Автосервис»;
   - **Database Password** — нажмите **Generate a password** и сохраните пароль,
     он понадобится в шаге 4;
   - **Region** — ближе к вашим клиентам (например, *Central EU (Frankfurt)*).
3. Нажмите **Create new project** и подождите 1–2 минуты, пока проект создаётся.

### Шаг 2. Две настройки в Supabase

1. **Запретите регистрацию посторонних.** Слева **Authentication** → **Sign In / Providers**
   → выключите **Allow new users to sign up** → **Save**. Аккаунт владельцу выдаёте только вы
   (шаг 9).
2. **Включите расписание уведомлений.** Слева **Database** → **Extensions** → найдите
   `pg_cron` и включите, затем найдите `pg_net` и включите.

Названия пунктов меню в Supabase иногда меняются. Если что-то не находится, ищите похожее
по смыслу или спросите меня.

### Шаг 3. Создайте аккаунт Cloudflare

Откройте [dash.cloudflare.com/sign-up](https://dash.cloudflare.com/sign-up), зарегистрируйтесь
по почте и подтвердите её. Больше ничего настраивать не нужно: сайт создаст команда в шаге 8.

### Шаг 4. Заполните файл настроек

1. Выполните:

   ```
   npm run cloud:prepare
   ```

   В первый раз команда создаст в папке проекта файл **`settings.env`** и остановится.

2. Откройте `settings.env` в простом текстовом редакторе:
   - **Mac:** правый клик по файлу → «Открыть в программе» → **TextEdit**;
   - **Windows:** правый клик → «Открыть с помощью» → **Блокнот**.

3. Впишите шесть значений сразу после знака `=`, без пробелов и кавычек. Всё копируется из
   Supabase (слева внизу шестерёнка **Project Settings**):

   | Строка | Где взять |
   |---|---|
   | `SUPABASE_URL` | **Project Settings → Data API → Project URL** (вида `https://…supabase.co`) |
   | `SUPABASE_PUBLISHABLE_KEY` | **Project Settings → API Keys → Publishable key** (начинается с `sb_publishable_`) |
   | `SUPABASE_SECRET_KEY` | там же → **Secret keys** → значок глаза → скопировать (начинается с `sb_secret_`) |
   | `DATABASE_URL` | кнопка **Connect** вверху страницы проекта → **Session pooler** → строка, начинающаяся с `postgresql://`. В ней замените `[YOUR-PASSWORD]` вместе со скобками на пароль из шага 1 |
   | `ADMIN_EMAIL` | ваша почта |
   | `SITE_NAME` | придумайте имя сайта: маленькие латинские буквы, цифры, дефис. Например, `moy-avtoservis` даст адрес `https://moy-avtoservis.pages.dev` |

   Если на странице API Keys есть только ключи `anon` и `service_role` (вкладка Legacy), они
   тоже подойдут: `anon` — в `SUPABASE_PUBLISHABLE_KEY`, `service_role` — в `SUPABASE_SECRET_KEY`.

   Если в пароле базы есть символы `@ : / # ? %`, задайте новый пароль из букв и цифр:
   **Project Settings → Database → Reset database password**.

4. Сохраните файл.

> **`settings.env` — это ключи от вашего приложения.** Никому его не пересылайте и не
> выкладывайте. Сохраните копию в надёжном месте (менеджер паролей, флешка): без этого
> файла нельзя будет обновлять сайт.

### Шаг 5. Подготовьте базу

```
npm run cloud:prepare
```

Команда создаст секретные ключи (они допишутся в конец `settings.env`), подготовит базу,
включит расписание уведомлений и опубликует демо-студии. Строки с `✔` означают успех.

Если появятся строки с `!`, сделайте то, что в них написано, и запустите команду ещё раз:
сделанное повторно не выполняется. Например, если команда попросит `AUTH_JWT_SECRET`:
**Project Settings → JWT Keys** → скопируйте **Legacy JWT secret** в строку
`AUTH_JWT_SECRET=` в `settings.env`.

### Шаг 6. Войдите в Supabase и Cloudflare с этого компьютера

```
npm run cloud:login
```

1. Сначала Supabase: нажмите Enter, в открывшемся браузере подтвердите вход. Если браузер
   покажет код, введите его в терминал и нажмите Enter.
2. Потом Cloudflare: в браузере нажмите **Allow**.

Это нужно один раз на этом компьютере.

### Шаг 7. Загрузите серверную часть

```
npm run cloud:functions
```

1–3 минуты. В конце должно быть `✔ серверные функции отвечают`.

### Шаг 8. Загрузите сайт

```
npm run cloud:site
```

2–4 минуты. В конце команда напечатает адреса, например:

```
GRAPHITE Detailing
  клиенты: https://moy-avtoservis.pages.dev/s/graphite/
  кабинет: https://moy-avtoservis.pages.dev/s/graphite/owner/
```

Затем один раз укажите адрес сайта в Supabase. Команда напечатает точные значения:
**Authentication → URL Configuration** → **Site URL** = адрес сайта; в **Redirect URLs** нажмите
**Add URL** и вставьте строку, которая заканчивается на `/s/*/owner/**` → **Save**.

### Шаг 9. Выдайте доступ к кабинету

```
npm run cloud:owner
```

Команда спросит номер студии, почту и пароль владельца. Под этой почтой и паролем владелец
будет входить в кабинет. Если запустить команду ещё раз с той же почтой, пароль сменится.

### Шаг 10. Проверьте

1. Откройте ссылку «клиенты» на телефоне и запишитесь.
2. Откройте ссылку «кабинет», войдите почтой и паролем из шага 9. Ваша запись должна быть
   в расписании.
3. Автоматическая проверка всего опубликованного:

   ```
   npm run cloud:check
   ```

**Как установить на телефон.** Android (Chrome): меню `⋮` → «Установить приложение» или
«Добавить на главный экран». iPhone (Safari): кнопка «Поделиться» → «На экран Домой».
Уведомления на iPhone работают только в установленном так приложении.

### Шаг 11 (необязательно). Включите AI-помощника

Подойдёт любой AI-сервис с «OpenAI-совместимым API». В кабинете сервиса возьмите три
значения и впишите их в `settings.env`:

```
LLM_BASE_URL=адрес API сервиса
LLM_API_KEY=ваш ключ
LLM_MODEL=название модели
```

Затем выполните `npm run cloud:functions`. С реальным AI-сервисом помощник ещё не проверялся;
скажите мне, какой сервис выбрали, и я проверю совместимость.

## Своя студия вместо демо

GRAPHITE и RotorLab — примеры. Они работают в демо-режиме: записи помечены как демо,
уведомления не отправляются. Чтобы сделать студию своего бизнеса, пришлите мне:

- название, адрес, телефон, часовой пояс;
- часы работы и выходные;
- посты или боксы и что на каждом делают;
- услуги с длительностью и ценой;
- логотип, квадратную иконку от 512×512 и 5–9 фотографий.

Я подготовлю папку студии (подробно процесс описан в [CLONE-IN-6-MINUTES.md](CLONE-IN-6-MINUTES.md)).
После этого:

```
npm run cloud:prepare
npm run cloud:site
npm run cloud:owner
npm run cloud:live
```

`cloud:live` переводит выбранную студию в рабочий режим: удаляет демо-записи и включает
уведомления. Команда откажет с понятным списком, если чего-то не хватает, например владельца.

## Как обновлять

| Что изменилось | Команды |
|---|---|
| Тексты, цены, услуги, фото студии | `npm run cloud:prepare`, затем `npm run cloud:site` |
| Приложение (новая версия проекта) | `npm run cloud:prepare`, `npm run cloud:functions`, `npm run cloud:site` |
| Нужен ещё один владелец или новый пароль | `npm run cloud:owner` |

Если скачиваете новую версию проекта (новый ZIP), скопируйте в новую папку свой `settings.env`
и выполните `npm install`.

Уже сделанные записи, клиенты, оплаты и фото, загруженные владельцем, при обновлениях сохраняются.
